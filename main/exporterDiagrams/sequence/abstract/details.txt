title CRUD — Details
participant Utilisateur
participant Frontend
participant Backend
participant BDD

Utilisateur -> Frontend: Consulter
Frontend -> Backend: Demande de lecture
activate Backend
Backend -> Backend: Vérifier la demande
alt Succès
  Backend -> BDD: Récupérer les informations
  activate BDD
  BDD --> Backend: BDD retournées
  deactivate BDD
  Backend --> Frontend: Résultats fournis
  deactivate Backend
  Frontend --> Utilisateur: Afficher DTO
else Échec
  Backend --> Frontend: Refus / impossible de traiter
  deactivate Backend
  Frontend --> Utilisateur: Afficher erreur
end
