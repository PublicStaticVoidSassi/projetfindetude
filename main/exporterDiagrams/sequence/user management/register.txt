participant Utilisateur
participant Backend
participant BDD

Utilisateur -> Backend: Soumettre les informations
activate Backend

Backend -> Backend: Vérifier les données

alt Données valides
    Backend -> BDD: Créer le compte
    activate BDD

    BDD --> Backend: Compte créé
    deactivate BDD

    Backend --> Utilisateur: Confirmation
else Données invalides
    Backend --> Utilisateur: Échec de l'inscription\nDonnées invalides
end

deactivate Backend
